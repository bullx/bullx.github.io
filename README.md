# Karan Chimedia - Modern Portfolio

Modern React portfolio with Tailwind CSS and Framer Motion animations.

## Features
- ✨ React 18 with Hooks
- 🎨 Tailwind CSS styling
- 🌙 Dark/Light mode toggle
- ✅ Framer Motion animations
- 📱 Fully responsive design
- 🎯 Smooth scrolling
- 📊 Interactive resume

## Setup

1. Install dependencies
```bash
npm install
```

2. Start dev server
```bash
npm start
```

3. Build for production
```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm install --save-dev gh-pages
npm run build
npm run deploy
```
